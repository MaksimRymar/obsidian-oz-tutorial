## What’s new and why it matters
I run a small storytelling channel. Every episode needs the same five things done in the same order: clean the script, generate narration, render a 1080p video, cut a vertical short, and verify the output is what I think it is. For a while I did that with a folder of half-remembered ffmpeg incantations. Then I wrote it down as one script.
