## What’s new and why it matters
Most LLM wiki setups I've seen are very good at one kind of memory and have almost none of the other. Karpathy's LLM Wiki pattern is the one everyone copies now: raw sources go in, the model writes linked Markdown pages, and answers come back with sources. That's great for facts . What the release process looks like, which service owns sync, what we decided about the queue. What it doesn't store is how you work . The fifth time my agent wrote release notes, it did the same five things it did the first four times: read the git log, searched the wiki for our changelog style, read that page, draf…
