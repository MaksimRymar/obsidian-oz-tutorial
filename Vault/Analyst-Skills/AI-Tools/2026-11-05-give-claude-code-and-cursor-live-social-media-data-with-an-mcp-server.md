## What’s new and why it matters
Ask an AI coding assistant "what are people saying about oat-milk lattes on Xiaohongshu this week?" and it will either guess or tell you it can't browse. The fix is an MCP server that exposes real data endpoints as tools. This walkthrough connects the Qovia MCP server (social, e-commerce and web data across Douyin, Xiaohongshu, Weibo, Bilibili, WeChat Official Accounts, TikTok, YouTube, X, Reddit and more) to Claude Code, Cursor and VS Code, then shows how to drive the same server from a plain Python script so your research is reproducible. Disclosure: I build Qovia, and this article was draft…
