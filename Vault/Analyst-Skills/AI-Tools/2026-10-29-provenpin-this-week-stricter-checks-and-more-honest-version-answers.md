## What’s new and why it matters
ProvenPin is a library of tested code recipes for AI coding models. Each recipe pins exact package versions, runs its own tests in a clean environment, and carries a receipt showing when it last passed. The goal is to help free and cheap models write code that actually runs. It is served over a free MCP server, no API key, no signup. This was a quality week rather than a growth week.
