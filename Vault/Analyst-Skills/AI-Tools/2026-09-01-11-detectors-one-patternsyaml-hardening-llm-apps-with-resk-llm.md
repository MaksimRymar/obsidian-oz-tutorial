## What’s new and why it matters
11 Detectors, One patterns.yaml: Hardening LLM Apps with resk-llm TL;DR resk-llm is a Python toolkit from resk that bundles 11 detectors for common LLM attacks: prompt injection, jailbreak, PII exfiltration, memory poisoning, and goal hijack. It ships as FastAPI middleware and is configured through a simple patterns.yaml file. The project is young, but the design is refreshingly direct: drop in the middleware, point it at your patterns, and start filtering malicious traffic.
