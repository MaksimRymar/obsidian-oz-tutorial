## What’s new and why it matters
In Python's "everything-is-an-object" data model , every piece of data is an object stored in memory. This includes numbers, strings, lists, functions, and even classes themselves. Every Python object has three unchangeable properties: Identity : The unique memory address of the object (checked via id() ). Type : The class/category of the object (checked via type() ). Value : The actual data stored inside the object.
