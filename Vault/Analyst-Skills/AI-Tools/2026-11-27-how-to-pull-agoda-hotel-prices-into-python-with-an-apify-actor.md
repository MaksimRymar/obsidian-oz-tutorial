## What’s new and why it matters

The output is JSON rows you can store, filter or load into a spreadsheet. Agoda shows a different price for every pair of dates you pick. Comparing a few hotels for one stay means opening each property page by hand and copying the numbers. This guide replaces that with one API call from Python.
