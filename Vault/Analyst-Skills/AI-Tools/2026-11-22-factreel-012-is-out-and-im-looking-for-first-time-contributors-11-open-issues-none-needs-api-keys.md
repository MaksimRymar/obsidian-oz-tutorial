## What’s new and why it matters
I'm a beginner in open source, and FactReel is my first project with outside contributors. In the last month three people have sent pull requests, and I learned more from reviewing them than from writing the code myself. Disclosure: I build it with Claude's help and review the result myself. What FactReel does It makes short vertical videos (YouTube Shorts, TikTok, Reels) from a list of facts you provide. An LLM writes the script, but it is only allowed to use the facts you gave it: numbers and dates are checked, rumours are labelled, and if the LLM fails there is a facts-only fallback. Voices…
