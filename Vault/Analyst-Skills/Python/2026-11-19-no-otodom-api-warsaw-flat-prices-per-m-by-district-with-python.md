## What’s new and why it matters
Otodom.pl is Poland's biggest property portal. On 15 November 2026 it listed 20,213 flats for sale in Warsaw alone. It has no public API for listings, so if you want that data in a spreadsheet or a notebook, you have to read the pages. This post pulls 1,000 Warsaw listings with about twenty lines of Python and works out what a square metre costs in each district. All the numbers come from a real run.
