## What’s new and why it matters
The conclusion first: an agent patch is not verified by the suite passing. It is verified by the assertions that executed in the head branch and did not execute in the base branch. Everything else is borrowed. Most agent pipelines report one bit: green or red. That bit hides two inflators. Skips inherited from the base branch silently shrink the evidence surface. Property tests that re-draw their randomness on every run make a pass non-reproducible by default. Fix both and the patch review gets shorter, not longer.
