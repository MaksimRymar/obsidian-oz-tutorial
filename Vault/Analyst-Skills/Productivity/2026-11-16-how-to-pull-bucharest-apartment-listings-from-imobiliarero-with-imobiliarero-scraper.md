## What’s new and why it matters
By the end of this tutorial you will have a Python script that pulls apartments for sale in Bucharest from imobiliare.ro into structured rows: asking price, surface, rooms, floor, year, seller and photo links. Imobiliare.ro is a Romanian property portal. Imobiliare.ro Scraper ( reventadata/imobiliare-scraper ) is the Apify Actor built to read its public search pages. You describe a search, and it returns one row per listing, up to the cap you set. The sample rows in this guide come from a run on 16 November 2026, not from an invented example.
