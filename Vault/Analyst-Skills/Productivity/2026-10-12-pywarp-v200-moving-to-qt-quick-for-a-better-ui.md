## What’s new and why it matters
I've been working on Pywarp for years, and with the latest v2.0.0 release, I've started moving the UI to Qt Quick for a better and more modern interface. Pywarp is an open-source alternative to the official Cloudflare WARP app, built with Python. It provides a desktop interface for managing WARP, with features like switching between MASQUE and WireGuard, configuring DNS modes, setting custom endpoints, and managing split tunneling.
