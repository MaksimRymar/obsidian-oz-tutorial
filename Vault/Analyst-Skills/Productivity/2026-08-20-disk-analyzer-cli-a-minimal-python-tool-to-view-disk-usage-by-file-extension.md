## What’s new and why it matters
Disk Analyzer CLI: Quick Disk Space Overview in Pure Python Sometimes you need to quickly see what's taking up space in your projects folder. This minimal CLI tool analyzes a directory and shows disk usage broken down by file extension — all using only Python's standard library. What It Does Scan any directory and get two views of disk usage: Summary mode : Top N extensions by size (default 15) Full breakdown mode : All extensions sorted by space consumed It walks the directory tree, sums file sizes per extension, and formats everything in human-readable units (KB, MB, GB, TB).
