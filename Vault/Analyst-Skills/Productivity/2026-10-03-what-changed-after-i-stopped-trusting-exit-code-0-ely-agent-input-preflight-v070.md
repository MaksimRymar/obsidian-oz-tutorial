## What’s new and why it matters
A few days ago I wrote about why I stopped treating exit code 0 from an AI coding agent as proof that the requested work was actually completed correctly. That idea has now turned into the next release of ELY Agent Input Preflight: v0.7.0 . The biggest change is a new layer called Generated-Code Admission . The goal is simple: before generated source code is allowed to contribute to a successful final result, ELY should independently check whether that source can be admitted at all.
