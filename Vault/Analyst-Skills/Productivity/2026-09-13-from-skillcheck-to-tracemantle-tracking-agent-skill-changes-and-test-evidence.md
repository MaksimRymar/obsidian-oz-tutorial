## What’s new and why it matters
I’ve renamed SkillCheck to TraceMantle and expanded its scope. The original project focused mainly on validating AI agent skill files. TraceMantle retains that functionality and adds support for tracking the files in a skill package, comparing changes, and checking whether previous test evidence still applies. The rename resolves a conflict with another project using the SkillCheck name. It also better reflects the tool’s broader purpose: helping developers assess both the contents of an agent skill and the evidence used to approve a particular version.
