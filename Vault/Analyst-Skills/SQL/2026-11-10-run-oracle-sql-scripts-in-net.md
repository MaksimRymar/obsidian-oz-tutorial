## What’s new and why it matters
ODP.NET script execution is designed for safer, automated Oracle database updates across cloud and AI workflows Key Takeaways The preview feature runs multiple SQL and PL/SQL statements directly from .NET applications without a separate scripting tool. Scripts can come from files, cloud storage, REST APIs, or any other source available as a .NET stream. Results, output parameters, metadata, and detailed errors are returned as JSON for easy processing and recovery.
