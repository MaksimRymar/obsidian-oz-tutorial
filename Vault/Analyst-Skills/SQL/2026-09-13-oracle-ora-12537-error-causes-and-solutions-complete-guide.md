ORA-12537: TNS Connection Closed – Causes, Fixes & Prevention What Is ORA-12537? ORA-12537 ("TNS: connection closed") occurs when the Oracle Net layer detects that a network connection between the client and the database server has been unexpectedly terminated. This error is typically raised by an intermediate network device (such as a firewall or load balancer) silently dropping idle TCP sessions, or by the Oracle Listener/database instance shutting down abruptly.
