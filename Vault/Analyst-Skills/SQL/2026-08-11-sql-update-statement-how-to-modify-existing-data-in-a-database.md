## What’s new and why it matters
INTRODUCTION Databases are constantly changing. A student's age may change, an employee's information may need correction, or a customer's details may be updated. Instead of creating a new record every time something changes, SQL provides the UPDATE statement to modify data that already exists in a table. The UPDATE statement is part of Data Manipulation Language (DML) because it changes the data stored in records without changing the structure of the table.
