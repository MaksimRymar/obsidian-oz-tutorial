## What’s new and why it matters
If you work with Oracle every day, try counting the windows you have open right now. There's probably a SQL client. Maybe a data modeler, or an ER diagram someone exported to PDF last spring. A spreadsheet where you pasted query results so your manager could see a chart. And somewhere, a text file with an execution plan you keep meaning to read properly. None of those tools is bad on its own. The trouble is the space between them. Every time you copy a result set into Excel, or redraw a relationship by hand because the diagram is out of date, you're doing work the tools should be doing for you…
