## What’s new and why it matters
Most people learning SQL hit the same problem I did: the courses are either textbook-heavy or video-heavy. You watch someone type SELECT * FROM customers, nod along, and forget it by Thursday. The one thing that ever made SQL stick for me was SQL Murder Mystery: a crime, a database full of evidence, and the only way to the culprit is a query. So I set out to build that idea into a whole course: a SQL detective game with a real course behind it. It's called QueryCase, and it launched in June.
