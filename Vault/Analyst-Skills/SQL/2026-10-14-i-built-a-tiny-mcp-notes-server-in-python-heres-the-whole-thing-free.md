## What’s new and why it matters
Most MCP (Model Context Protocol) examples are either toy "hello world" servers or sprawling frameworks. I wanted the smallest useful thing: a notes server an AI assistant can actually use — create a note, list notes, search notes — backed by a plain local JSON file. No database, no cloud, no account. It's open source (MIT) and free: Code: https://github.com/bradraylucas-eng/mcp-notes-server One-click-ish install via Smithery: https://smithery.ai/servers/bradraylucas/mcp-notes-server Packaged .mcpb bundle on the v1.0.0 release page, if you use Claude Desktop What it does Three tools, that's it…
