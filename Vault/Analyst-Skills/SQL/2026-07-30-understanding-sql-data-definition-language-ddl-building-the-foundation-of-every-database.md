## What’s new and why it matters
What is Data Definition Language (DDL)? Data Definition Language (DDL) is a subset of SQL that deals with the structure of a database rather than the data itself. Unlike Data Manipulation Language (DML), which focuses on inserting, updating, and deleting records, DDL is responsible for creating and organizing the objects that hold the data.
