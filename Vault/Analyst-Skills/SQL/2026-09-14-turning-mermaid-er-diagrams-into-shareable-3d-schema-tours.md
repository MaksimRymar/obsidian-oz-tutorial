## What’s new and why it matters
Turning Mermaid ER diagrams into shareable 3D schema tours Mermaid erDiagram is great for docs and PRs. It’s less great when the schema gets dense: boxes overlap, FK lines tangle, and “just zoom out” stops helping. I built Schema3D for that moment: open a Mermaid ER (or SQL / DrawDB) in the browser, explore it in 3D, and share a URL that recreates the view. No live database connection, no account. Why 3D helps (sometimes) 2D ERDs optimize for printing and README screenshots.
