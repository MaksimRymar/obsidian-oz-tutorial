## What’s new and why it matters
I've been building Zentro, a desktop SQL IDE (Windows, macOS, Linux) that's organized around projects rather than loose connections. It supports PostgreSQL, MySQL, SQL Server and SQLite, and it's written in Go + Wails on the backend with React + TypeScript on the frontend, shipping as a single executable.
