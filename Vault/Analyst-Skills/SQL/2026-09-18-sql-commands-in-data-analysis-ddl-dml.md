## What’s new and why it matters
Data Definition Language (DDL) DDL commands define and manage the database schema. These statements affect the structure of tables, indexes, and other database objects. Common DDL commands include CREATE, ALTER, DROP, and TRUNCATE. These are used to build, modify, or remove database objects. Data Manipulation Language (DML) -_ DML commands interact with the data stored within the database objects.__ They are used to retrieve, insert, update, or delete records.
