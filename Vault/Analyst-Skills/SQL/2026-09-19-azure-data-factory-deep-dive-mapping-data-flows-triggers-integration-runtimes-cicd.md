## What’s new and why it matters
Azure Data Factory is the serverless orchestration service that most Azure data teams reach for first: you author pipelines that move and transform data, and the service provisions the compute for each run, bills you per activity execution, and never asks you to keep a server warm. It is not a database, not a Spark cluster you manage, and not a single connector — it is the control plane that wires connectors, compute, and schedules together.
