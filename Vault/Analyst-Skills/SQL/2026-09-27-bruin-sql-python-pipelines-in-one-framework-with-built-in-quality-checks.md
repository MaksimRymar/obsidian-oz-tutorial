## What’s new and why it matters
bruin is the open-source data pipeline framework that collapses four tools into one: it runs your SQL transforms, executes your Python jobs, ingests data from external sources, and enforces data-quality checks — all from a single Go binary and a folder of files you keep in version control. You do not wire dbt to Airbyte to Great Expectations to an orchestrator and hope the seams hold. You write assets — SQL files, Python files, or small YAML files — each carrying its own metadata in a comment block, and you type bruin run .
