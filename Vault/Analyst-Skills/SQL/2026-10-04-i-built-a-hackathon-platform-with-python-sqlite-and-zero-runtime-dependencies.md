## What’s new and why it matters
What if, instead of building a project for a hackathon, you had to build the platform that actually judges the hackathon? That was the prompt behind DOGFOOD 2026 : "Build the platform that will judge you." Most hackathon projects are quick prototypes with forty npm packages, three mock APIs, and a prayer. For this challenge, I decided to go in the exact opposite direction: One Python process. One SQLite database. Zero runtime third-party dependencies. Zero outbound network calls. No Flask. No FastAPI. No Django. No Redis. No PostgreSQL. No CDN. Just Python's standard library, SQLite, vanilla C…
