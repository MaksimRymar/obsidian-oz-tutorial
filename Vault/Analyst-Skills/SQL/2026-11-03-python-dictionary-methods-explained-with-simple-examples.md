Python dictionary methods are the built-in tools for working with key and value data: get() reads a value safely, keys() , values() and items() let you loop through a dictionary, update() adds or changes several pairs at once, pop() removes a key and gives you its value, and setdefault() adds a key only if it is missing. Learn these few methods well, and dictionaries stop feeling scary and start feeling like the helpful notebook they really are.
