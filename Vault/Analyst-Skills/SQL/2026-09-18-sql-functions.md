## What’s new and why it matters
What are SQL functions? A SQL function is a built-in operation that takes some input - a column, a value, or a set of rows - and returns a computed result. They fall into two broad categories: Aggregate functions - operate across multiple rows and collapse them into a single value: COUNT , SUM , AVG , MIN , MAX . Scalar functions - operate on a single value at a time and return one result per row: string functions ( UPPER , LOWER , CONCAT , LENGTH ), numeric functions ( ROUND , ABS ), and date functions ( NOW() , DATE_PART , AGE() ).
