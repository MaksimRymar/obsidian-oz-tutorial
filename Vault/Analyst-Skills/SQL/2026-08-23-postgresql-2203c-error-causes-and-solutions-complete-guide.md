## What’s new and why it matters
PostgreSQL Error 2203C: sql_json_object_not_found PostgreSQL error code 2203C ( sql_json_object_not_found ) occurs when a SQL/JSON path expression fails to locate the specified key or object within a JSON document. This error is thrown by SQL/JSON functions such as JSON_VALUE , JSON_QUERY , JSON_TABLE , and related functions introduced in PostgreSQL 16 as part of the ISO SQL standard.
