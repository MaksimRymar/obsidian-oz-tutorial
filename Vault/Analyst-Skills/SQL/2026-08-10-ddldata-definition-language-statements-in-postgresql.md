## What’s new and why it matters
In PostgreSQL, objects including users, virtual warehouses, databases, schemas, tables, views, columns, functions, and stored procedures are created, modified, and altered using Data Definition Language (DDL) commands. A collection of SQL commands called Data Definition Language (DDL) is used in PostgreSQL to specify and control the structure of database objects. DDL statements mostly deal with the creation, modification, and removal of objects like tables, databases, schemas, views, and indexes, in contrast to commands that work with the data stored in tables.
