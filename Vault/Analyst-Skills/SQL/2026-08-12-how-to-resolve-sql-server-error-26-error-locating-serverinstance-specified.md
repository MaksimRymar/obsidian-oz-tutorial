## What’s new and why it matters
SQL Server Error 26 is a common connectivity error that appears when a client application, SQL Server Management Studio (SSMS), or another tool cannot locate the specified SQL Server instance. The error usually indicates a problem with the server or instance name, SQL Server service, SQL Server Browser, network protocols, DNS resolution, or firewall configuration.
