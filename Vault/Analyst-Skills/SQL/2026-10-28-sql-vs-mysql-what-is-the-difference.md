## What’s new and why it matters
Originally published on CodingCush . SQL and MySQL are not rivals — they are not even the same kind of thing. SQL is a language: the standard way of asking a database to store, find, change and delete data. MySQL is a piece of software: a database program that understands SQL and does the actual storing. In short, SQL is the language you speak, and MySQL is one of the databases that listens. Every MySQL database is worked with using SQL, but SQL is also spoken by many other databases — PostgreSQL, SQLite, Microsoft SQL Server and more.
